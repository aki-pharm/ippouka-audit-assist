# 一包化監査アシスト

一包化の1包目を監査するとき、処方箋から「朝・昼・夕の袋に入るはずの錠剤」を、添付文書由来の刻印・形・色・大きさつきのイメージ図で並べて見せるスマホWebアプリです。
カメラに錠剤を判定させません。判断するのは薬剤師。このツールの役割は「調べる手間を減らすこと」です。

> Built with Claude: Japan 2026（2026-11-02 〜 11-08）の期間中に新規に制作しました。チーム「ちーむおひとりさま」（現役病院薬剤師 AKI ＋ Claude Code）。

## なぜカメラで判定しないのか
これまでの機器は、袋の中身をカメラで読み取って判定するものでした。白い錠剤は裏を向けば刻印が見えず、同じ色・同じ大きさの錠剤は写真では区別しづらく、専用機は大型で高価です。
本作品は発想を逆にしました。袋を読むのではなく、処方箋から「入っているはずの錠剤」を先に示す。判定するのは薬剤師。だから身近なスマホで、どの施設でも使えます。

## 画面の流れ
1. 処方箋の薬剤欄を撮る（サンプルの架空処方箋でも試せる）
2. Claude が薬・規格・朝昼夕の錠数を表に書き起こす。読み取りは下書きで、すべて手で直せる。検算が合わない行は黄色
3. 別包の指示・施設ルール（PTPのまま等）で袋に入れない薬を外す。処方箋の「□コ」（手巻き）とマスタの分包方法を突き合わせる
4. 服用時点ごとのイメージ図。錠剤を実寸比で描き、刻印（表・裏）を表示。同じ袋に形・色・大きさが近い錠剤があれば同じ印をつけ「刻印で区別」と知らせる（ルール判定。AIは使わない）
5. 錠剤をタップすると登録情報（刻印・色・大きさ・一包化区分・分包方法・添付文書の記載の抜粋・改訂年月・確認者）。「添付文書を開いて確かめる」で PMDA の PDF の該当ページへ

## Claude の使い方（人が確認してから使う）
| 場面 | 何をさせたか | 人が何をしたか |
|---|---|---|
| 添付文書PDF → 外観マスタ | `npm run extract`。JSON スキーマ固定で刻印・色・形・大きさ・根拠の文言・ページを書き写す。推測で埋めず、読めなければ「未確認」。刻印の「なし」と「未確認」を区別 | 薬剤師が添付文書と実物の錠剤に1つずつ突き合わせ、確認者・確認日つきで verified に（28品目） |
| 処方箋の写真 → 表 | `app/api/read-rx`。JSON スキーマ固定。患者情報は出力しない。別包・一包化の指示、□コも拾う | 画面で直して確定 |
| 開発そのもの | Claude Code のクラウド環境で、PMDA からの PDF 取得、抽出、CSV 変換、画面、デモ動画のアニメーションと組み立てまで | 設計の判断、現場ルールの言語化、確認、撮影 |

## 安全とデータ
- Claude が出すのは「添付文書の書き写し」と「処方箋の書き起こし」だけ。用量の妥当性・処方の是非・薬の推奨は出さない。画面下部に常時「本ツールは監査を支援する情報表示です。判断は薬剤師が行います」
- 似た外観の注意表示はルール判定（同じ形・同じ色・長径の差 1.0mm 以内）
- 患者情報の入力欄はなく、処方箋・1包目の画像はサーバに保存せず、ログにも出さない
- 実在の患者情報・院内データ・病院名は使わない。`public/samples/` の処方箋は架空
- 添付文書PDFはリポジトリに含めない（出典URL・改訂年月・ページ・根拠の文言をマスタに持つ）
- 公開URLは共通パスコードで保護（`APP_PASSCODE`）。API 呼び出しは1日の上限（`DAILY_API_CALL_LIMIT`）

## 使い方（開発）
```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY（または CLAUDE_API_KEY）, APP_PASSCODE を設定
npm run dev
```
- `npm run fetch-pdfs`：`data/pmda-sources.json` の URL から添付文書PDFを `pdfs/` に取得（`--apply` で出典URL・改訂年月・性状ページをマスタに登録）
- `npm run extract -- pdfs/xxx.pdf --id <マスタid> --strength 5mg --url <PMDAのURL>`：添付文書PDFから外観情報の下書き（`data/drafts/`）
- `npm run csv -- export | import | apply-drafts`：マスタの CSV 書き出し／取り込み／下書きの反映
- `node scripts/make-samples.cjs`：架空の処方箋サンプル画像を作り直す
- `node scripts/make-intro.cjs` / `make-slides.cjs` / `make-video.cjs`：デモ動画のアニメーション・スライド・組み立て（素材は `captures/`、コミットしない）

Claude Code のクラウド環境では `ANTHROPIC_API_KEY` という名前の環境変数が無効化されるため、`CLAUDE_API_KEY` でも読めるようにしてあります。

## 今後
- まず自分の職場で、採用医薬品から。マスタは「添付文書 → Claude 抽出 → 薬剤師の確認」の同じ手順で増やせる
- 全医薬品の親マスタ（外観・出典）と、施設ごとの運用マスタ（採用品・一包化区分・分包方法）を分けて、様々な施設へ
- 刻印データが集まれば、刻印を打ち込むとイメージ図が出る索引として、持ち込み薬の鑑別にも

## 対象外
半錠、散剤、眠前など朝昼夕以外の服用時点。カプセルは外観の図を描かず「PTP で確認」の扱い。
