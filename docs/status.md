# 作業の掲示板（全セッション共通）

セッション同士は互いの会話が見えない。連絡はこのファイルと GitHub の Issue だけで行う。

## ルール
1. **始める前に** `git pull origin main` して、このファイルを読む
2. **終わったら**「報告」に追記して commit し、**main に** push する（新しい報告を上に）。自分のブランチに置いたままにしない
3. 自分の持ち場以外のファイルは変えない。必要なら「依頼」に書く
4. 「できた」は数字で書く（例：テスト 7/7 通過、怪しい品目 41 件）。「できました」だけの報告はしない
5. 作った人は自分の仕事を採点しない。採点は品質（相談セッションが起こす別の担当）が行う
6. 判断に迷ったら止めて「AKI の判断待ち」に書く。推測で進めない
7. `data/private/`（施設の採用品・カセット）は絶対に commit しない。このリポジトリは公開。掲示板にも採用品の品目名・YJ コード・カセット番号は書かず、件数だけにする
