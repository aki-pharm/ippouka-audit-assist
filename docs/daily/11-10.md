# 11/10（火）：親マスタの下書きを、プログラムで照合した

## きっかけ
- 入賞・ファイナリストの3作品（よみどころ、おもいでつむぎ、EVAC LAYER）のリポジトリを読んだ。共通していたのは「Claude の出力を、Claude 以外のもので確かめ、数字で示す」こと。本作品は確認を人の目だけで行い、検証記録（`docs/validation.md`）は空のまま提出していた
- 親マスタの下書きには根拠の文言（source_quote）とページが入っている。材料はあったので、照合をプログラムにした

## やったこと
- `scripts/verify-quotes.cjs`（`npm run verify-quotes`）：下書き 4,331 ファイルの根拠の文言・刻印・大きさ・色が、添付文書PDFのそのページの文字にあるかを調べる。Claude の API は使わない
- 添付文書PDF 2,654 文書を PMDA から取り直した（約20分、1.6GB、コミットしない）。6 文書は PMDA がエラーを返した（11/6 以降の改訂で URL が変わった可能性）
- 結果は `data/parent/verify/`（読み方は同フォルダの README）

## 結果（4,860 行）
- すべての検査を通った 3,961／目で見る 350（高 103・中 238・低 9）／照合不能 549。足すと 4,860 で抜けなし
- 文字が取り出せた 4,311 行のうち、根拠の文言が一致 4,177（96.9%）、近似 131、不一致 3
- 検査が働くかの試し（500件）：添付文書に無い刻印を足す → 99.8% 検出。刻印を 1 文字変える → 84.6%。長径を 0.3mm 変える → 83.4%

## 見つかったこと
1. 根拠の文言は一字一句の写しではないものが多い（そのまま本文にあるのは 18.6%）。表の見出しとマスを Claude がつないで書いている。値は合っているが、指示「文言そのまま」は守られていなかった
2. 本文に無い数字が入っている品目（優先度 高）：カプセルの寸法（号数からの推測の可能性）、外形図の寸法、単位の換算
3. ノイキノン錠10mg：色の表現の順番が入れ替わっていた
4. 文字が取り出せない添付文書が 298 文書（526 行）。プログラムでは確かめられない

## 作っている途中で直した、照合プログラム側の誤り（下書きの誤りではない）
- 文言全体を一字一句で探したら、ほとんど不一致になった → 語ごと・断片の組み立てで測るようにした
- 表の隣り合う数字が「7.07.1」とつながり、7.1 が見つからなかった → 数字は空白を残した本文で探す
- 取得の途中で走らせたら、空の文字を覚えてしまい「文字が取り出せない」が増えた → 空は覚えない。本番の前に作り直した
- 文字化けしたPDFを「日本語がある」と数えていた（文字化けは漢字に見える記号になる）→ ひらがなの数で判定
- 試しで、足した偽の刻印を 300 件中 13 件見逃した（2 文字の断片をつなぐと、長い文言に紛れた短い偽物が通る）→ 見つからない 2 文字以上のまとまりがあれば「一致」にしない

## 限界（確かめられなかったこと）
- 隣の規格との取り違え（どちらの値も同じページにあるため）
- 図だけに載っている刻印・寸法
- 文字が取り出せないPDF の 526 行
- 実物の錠剤と合っているか
