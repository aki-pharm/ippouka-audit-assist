# なぜ一包化の監査が大変か（AKI の言葉、11/3）

提出文・動画の「誰が、どんな場面で、どれくらい困っているか」の元になるメモ。原文のまま残す。使うときは要点を絞る（Claude の整理は末尾）。

---

高齢者の増加もそうですが、心不全とか糖尿病とか、高齢者になるほど薬の内服錠数が多くなります。
ポリファーマシーといわれ、数年前から問題になっています。
そこで、調剤報酬でも残薬の削減とか重複薬剤の削除にも加算があてられ、国レベルでも問題になっています。
もちろん薬剤師として処方削除に貢献したいものの、やはり飲み続けないといけない薬があるのも事実です。
そうなると患者がひとりで服薬していくために一包化などの支援が必要になっていきます。
薬剤師に求められる仕事は多く、さらに一包化にも時間がかかる。
とくに医療過疎地の薬局では薬剤師1名で対応することも少なくありません。
その時に患者さんのヒアリングや指導をしながら一包化を作成するとなると時間との勝負になります。
こういった支援ツールを作ることにより、薬剤師が添付文書にさらにアクセスしやすくなり、監査をスムーズに行うことができるようになります。
建前上、処方箋監査は調剤前（一包化作成前）に行うのが正しいフローですが、現状は同時並行の部分が多いです。
1年目や2年目薬剤師は特に知識が浅い、さらに50代以降の薬剤師も刻印が見えない、新規の薬がどんどん発売されていくという時代です。
その中で、薬剤師の実務レベルにかかわらず安定した監査を提供するためにこのツールを考えました。
日本ではジェネリック医薬品が8割以上をしめており、一つの薬剤にたくさんの会社が作成しています。会社によってもデザインが違います。
出荷調整などで既存のメーカーが入手できない場合、他社メーカーで対応することもあります。

この1週間では難しいものの、これからは処方箋を読み取った段階で出荷調整のお知らせや流通状況をアラートする機能を入れたい。
そうすれば、いち早く薬の入荷状況を知ることができるので、素早い患者対応を行えると考えています。
現状としては薬価収載されている医薬品のマスタを作成して、各施設に導入することを目標としたいです。

## 使いどころの整理（Claude）
- **動画・提出文の冒頭に使う（具体的で強い）**
  - 1年目・2年目は知識が浅い／50代以降は刻印が見えない／新薬はどんどん出る → 実務レベルによらず同じ監査ができるように
  - 医療過疎地では薬剤師1人。聞き取りと指導をしながら一包化を作る → スマホ1台で済む設計の理由
  - ジェネリック8割、会社ごとに見た目が違う、出荷調整で別メーカーに変わる → 一般名＋規格で照合して採用品に置き換える機能の理由
- **背景として1文だけ**：高齢化とポリファーマシーで錠数が増え、一包化の支援が必要になっている
- **書かない・言い換える**

  - 「監査は本来調剤前だが同時並行」→ 「1包目を見ながら確かめる場面は現実に多い」
- **将来構想（1行ずつ）**
