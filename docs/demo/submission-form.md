## プロジェクト概要（500字以内。指定の1文から始める）

このプロジェクトは、〔一包化の監査をする薬剤師〕の〔錠剤の見分けが経験や知識に左右される問題〕を〔処方箋から袋に入っている薬剤を刻印付きのイメージ図で示し、薬剤師が現物と突き合わせて判定する形〕に変えるものです。

高齢化とポリファーマシーで、服薬を簡素化する一包化（1回分を1袋にまとめる調剤）が増え、業務を圧迫しています。監査は最初の1包が基準ですが、内服薬は7,000品目超、製薬会社ごとに見た目が違い、新人や応援には似た錠剤やカプセルが同じに見えます。経験で速さと正確さに差が出て、最も危ないのが「似た見た目の違う薬」の見逃しです。

カメラで判定する機器は撮影条件が難しく、大型で高価。誰にでも届く形にしたくて発想を転換しました。処方箋の写真を Claude が表にし、添付文書由来の外観マスタと照合して服用時点ごとに錠剤を図で並べ、似た錠剤には「刻印で区別」と知らせます。根拠の添付文書（PMDA）にもワンタップ。判定は薬剤師、アプリはスマホで動く道具です。

マスタは Claude が添付文書から書き写し、薬剤師の私が実物と突き合わせて確認。同じ手順で拡充でき、持ち込み薬の鑑別の索引にもなります。

## 開発中に一番詰まった場面（①〜④の順）

①何を作ろうとしていましたか
添付文書PDFから錠剤の外観（刻印・色・大きさ）を Claude API で抜き出すスクリプトを、Claude Code のクラウド環境で動かそうとしていました。

②Claude にどのように指示しましたか
環境設定に API キー（ANTHROPIC_API_KEY）を登録したうえで、「キーが読めることを確認して、PDF を取得し、まず3件抽出して結果の見方を報告して」と指示しました。

③何が起きましたか
2セッション続けて「キーが読めない」と報告されました。Claude は原因の候補（別の環境に登録した、ネットワークシークレット側に登録した、保存前にセッションを開始した）を挙げましたが、どれも当てはまりませんでした。3セッション目で、Claude Code のクラウド環境は ANTHROPIC_API_KEY という名前の変数だけを意図的に無効化している（設定画面の注意書きがその意味だった）と突き止めました。

④期待していた結果と何が違いましたか／どのように対処しましたか
キーを登録すればすぐ動くと思っていましたが、変数名そのものが原因でした。コード側を ANTHROPIC_API_KEY と CLAUDE_API_KEY の両方を読むように変え、クラウド環境では後者で動かしました。キーがスクリーンショットに写ったため再発行もしました。待っている間はキー不要の作業（PMDA からの PDF 取得、出典 URL・改訂年月の登録）を先に進めたので、全体の遅れは半日で済みました。

## 開発に必要な公式の情報が十分見つけられましたか
おおむね見つかりました。Claude API の構造化出力（zod スキーマ）と PDF 入力は公式ドキュメントと SDK の型定義で足りました。足りなかったのは、Claude Code のクラウド環境で ANTHROPIC_API_KEY が無効化される仕様の説明で、設定画面の短い注意書きだけでは意味が分からず、2セッション分の時間を使いました。「この変数名はこの環境では使えません。別名で登録してください」と書いてあれば防げたと思います。

## Claude を使った感想と改善してほしい点（①〜③の順）

①日本語や日本の業務で使う立場から気づいた欠点と利点（具体例）
利点：添付文書という日本固有の文書を、「組成・性状」の表から刻印・色・直径・厚さまで、表のセル構造を理解して書き写せました。文字が取れないPDF（フォント埋め込みの都合）も画像として読め、28品目で読み違いはありませんでした。「読めない項目は未確認と答える」「社名マークだけなら刻印なし」という現場の区別を指示どおり守ったのが大きいです。
欠点：日本語の処方箋の読み取りで、「1-0-2-0-0-0 で投与」のような施設独自の記法や「□コ」（手巻き）の印は、説明しないと読み取れません。業務の暗黙知は人が言語化して渡す必要があります。また、動画のアニメーションを作ったとき、Noto Sans JP の一部の漢字（「化」など）が別フォントで描かれる問題に Claude 自身が気づかず、私が指摘するまで続きました。

②他の AI ツールと比べて劣る点と優れる点
比較なし。

③一つだけ直せるとしたら何か、その改善で何が作れるようになるか
Claude Code のクラウド環境から、許可したサイトの画面（画像）を見られるようにしてほしい。今回は QLife や Google ドライブに置いた錠剤の写真を Claude が見られず、私が1枚ずつチャットに貼って確認しました。写真を置いた場所を Claude が直接見られれば、採用医薬品 1,000〜2,500 品目の外観マスタを、同じ「抽出→薬剤師が写真で確認」の手順で現実的な時間で作れるようになります。
