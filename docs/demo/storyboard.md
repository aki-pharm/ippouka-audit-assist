## 既存との違い（一言で言えるように。アドバイザーの助言より）
- 既存：**錠剤を機械やカメラに判定させる**（刻印チェック機、画像判定）。大型・高価で使える施設が限られ、カメラ判定は白い錠剤で「要確認」だらけになる
- 本作品：**判定しない**。ベテランが頭の中でやっている「この処方なら袋にはこれが入るはず。あの白いのは刻印○○のはず」をそのまま画面に出す。だから身近なスマホで、どの施設でも使える
- 一言：「カメラに当てさせるのではなく、薬剤師の頭の中の『答え合わせ表』を画面にした」

## 禁止例（医療アドバイスを行うAI）への向き合い方（動画では言わず、提出文と README に）
- Claude が出すのは「添付文書に書いてある外観の書き写し」と「処方箋に書いてある内容の書き起こし」だけ。用量の妥当性・処方の是非・薬の推奨は出さない（言葉づかいの方針 §8）
- 似た外観の注意表示はルール判定で AI を使わない
- 患者情報は入力欄がなく、画像も結果も保存しない
