# 親マスタの下書きの照合（2026-11-10）

Claude が添付文書から書き写した下書き（`../drafts/claude-sonnet-5-5/`）を、**Claude を使わず、プログラムで**添付文書PDFの文字と照らし合わせた結果。
Claude の書き写しを Claude に確かめさせない、というのが目的。

```bash
npm run verify-quotes                 # 全品目を照合して、このフォルダに結果を書く（約4分。PDF は pdfs/parent/ に要る）
npm run verify-quotes -- --selftest   # 検査が働くかの試し（わざと値を書き換えて、見つけられるかを数える）
```

## 検査が働くかの試し（`selftest.json`）

すべての検査を通った品目から 500 件を取り、値をわざと書き換えて、見つけられるかを数えた。

| 書き換え | 見つけた |
|---|---|
| 根拠の文言に、添付文書に無い刻印（ZZQ9917）を足す | 499/500（99.8%） |
| 刻印の最後の 1 文字を変える（141 → 142） | 428/500（85.6%）（pdftotext 時は 423） |
| 長径を 0.3mm 大きくする | 413/500（82.6%）（pdftotext 時は 417） |

見つけられなかった約 16% は、書き換えた後の値がたまたま同じページにある場合（多くは同じ添付文書に載っている隣の規格の値）。**これがこの照合の限界**。

## この照合で分かること・分からないこと

分かること：
- 下書きの刻印・大きさ・色・根拠の文言が、添付文書のそのページに**文字として存在する**こと（作り話でないこと）

分からないこと：
- **隣の規格との取り違え**。1 つの添付文書に 1mg と 2mg が載っていて、2mg の刻印を 1mg に書いていても、どちらもページにあるので通ってしまう
- **図だけに載っている情報**。刻印や寸法が外形図（画像）にしか無い添付文書では「どのページにも無い」になる。誤りとは限らないが、プログラムでは確かめられない
- **文字が取り出せないPDF**（298 文書、526 行）。図として作られたPDFや、文字化けするPDF。人が見るか、別の方法（OCR など）が要る
- **実物の錠剤と合っているか**。これは薬剤師が確かめる

## 見つかったこと

1. **根拠の文言は「一字一句の写し」ではないものが多い。** そのまま本文にあるのは 800 行（18.6%）だけ。残りは、表の見出しとマスを Claude がつないで書き起こした文（例：表の「直径」「約14mm」→「直径約14mm」）。値は合っているが、抽出の指示「文言そのまま」は守られていない。次に抽出するときは、指示を「表のマスの文字をそのまま、マスごとに区切って」に直す
2. **本文に無い数字が入っている品目がある（優先度 高）。** 例：カプセルの長径・短径（アモキサンカプセル 14.5×5.3mm。本文には「4号硬カプセル」としか無い。号数からの推測の可能性）、外形図の寸法（テシプール錠、エピナスチン錠「イワキ」）、単位の換算（ボグリボースODフィルム「約80μm」→ 0.08mm）。「推測で埋めない」の指示に反していないか、人が見る
3. **表現の入れ替わり。** ノイキノン錠10mg：添付文書「黄色〜橙黄色」→ 下書き「橙黄色〜黄色」
4. **添付文書の改訂で URL が切れる。** 11/6 に紐づけた 2,654 文書のうち 6 文書（8 品目）が、11/10 には PMDA でエラーになった。出典URLは改訂のたびに変わる

## ファイル

- `quote-check.csv`：全 4,860 行。品目ごとの判定と、探した値
- `needs-review.csv`：目で見る 350 行。`priority`（高・中・低）と `review_reason`（理由）つき。優先度の高い順
- `unable.csv`：照合不能 549 行と理由
- `summary.json`：件数。`selftest.json`：試しの結果

主な列：`quote`（根拠の文言の判定）、`ratio`（組み立てられた割合）、`missing`（本文に見つからなかった所）、`front_in_text`／`back_in_text`（刻印が本文にあるか）、`long_in_text`／`short_in_text`／`thick_in_text`（大きさ）、`color_in_text`（色）、`found_page`（実際に見つかったページ）

## 判定の決まり

- 比べる前にそろえる：全角と半角、波線・ハイフンの表記ゆれ、空白。根拠の文言は句読点と括弧も除く
- 根拠の文言
  - 一致（全文）：そのまま本文に入っている
  - 一致（語）：空白や「/」で区切った語が、すべて本文に入っている
  - 一致（組み立て）：本文にある 2 文字以上の断片をつなぐと 95% 以上が組み立てられ、残りはどれも 1 文字まで
  - 近似（要目視）：80% 以上が組み立てられるが、本文に無い 2 文字以上のまとまりがある（多くは図にだけある刻印）
  - 不一致：それ未満
- 根拠のページに無ければ前後 2 ページも探す
- 数字は「7」を「7.0」としても探す。表の隣のマスの数字とつながらないよう、空白を残した本文で探す
- 照合不能（文字が取り出せない）：根拠のページとその前後に、ひらがなが 50 字未満
